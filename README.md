# Wallet Score Checker

A production-style Next.js 15 starter with RainbowKit wallet connection.

## Stack
- Next.js `15.2.6`
- React `19.2.1`
- RainbowKit `2.x`
- wagmi `2.x`
- viem `2.x`

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run dev server:
   ```bash
   npm run dev
   ```

## Build
```bash
npm run build
```
